## Technology constraints

This project is a React + Node.js + Express + Prisma application.

Do not create Python files, Python scripts, virtual environments,
requirements.txt, pyproject.toml, Flask, FastAPI, Django, or Python-based
utility scripts.

All server-side, migration, testing, cleanup, email, upload, and deployment
logic must be implemented in JavaScript or TypeScript.

Before creating a new file, prefer modifying an existing JavaScript or
TypeScript module.

Do not introduce a second backend runtime.
